# 方法与来源

本实验由本地MIR计算、当前Codex文字模型的设计解释、内置imagegen图像生成三个阶段组成。所有本地文件在“临时测试_v1”内；原FLAC保持不变。

## 实际运行范围

- 使用 FFmpeg 生成不裁剪的22,050 Hz单声道PCM分析副本。
- librosa 0.11.0计算短时能量、频谱质心、频谱平坦度、频段能量比例、色度特征、MFCC、HPSS谐波/打击成分指标、起音与节拍。
- 使用节拍同步特征的多尺度变化曲线，以及多个分段数量下的时间约束聚类，形成结构边界候选；记录复核决定。
- 这些方法不提供乐器识别、曲风分类、效价/唤醒情绪预测或歌词识别。本版相应字段保留为空。
- 本版没有声称运行Essentia预训练模型、All-In-One、Demucs、旋律转写或文字API。
- 文字设计由当前Codex会话中的LLM读取测量结果完成；内置imagegen负责图像生成。

## 分段解释

“v1工作分段”用于本次视觉探索。以信号特征和相似性检查支持边界，不等同于人工听辨确认的曲式。
未经过听辨的主歌、副歌、桥段标签不写入事实字段。
多参数方法的一致程度不是概率，也不能替代人工听辨。
